## 📌 Descripción

**CV AI Assistant** es una herramienta pensada para ayudar a los candidatos a destacar en sus procesos de selección. La aplicación analiza la estructura y el contenido de un currículum vitae, ofreciendo recomendaciones de mejora, optimización de palabras clave para sistemas ATS (*Applicant Tracking Systems*) y sugerencias personalizadas según la descripción del puesto de trabajo deseado.

---

## 🚀 Características Principales

* 📊 **Análisis de CV:** Evaluación completa del contenido, estructura y nivel de impacto de las descripciones de experiencia laboral.
* 🎯 **Optimización para ATS:** Identificación y sugerencia de palabras clave esenciales para superar los filtros automatizados de RRHH.
* ✍️ **Generación y Sugerencias:** Redacción mejorada de resúmenes profesionales, logros clave y cartas de presentación personalizadas.
* 🔄 **Match con Ofertas de Empleo:** Comparación directa entre tu perfil y los requisitos de una vacante específica para resaltar tus fortalezas.
